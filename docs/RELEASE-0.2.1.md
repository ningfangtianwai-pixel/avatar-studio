# Avatar Studio v0.2.1 · 首个公开预览版

数字人口播工作台：在本地管理数字人形象、声音、文案、生成任务与成片，串联 Qwen3-TTS、MuseTalk 和 FFmpeg。

本数字人系统由 **Manny 与 Codex 协作完成**。作者与维护者：Manny。原创工作台代码使用 MIT，底层模型与第三方依赖保留各自许可证；本项目不代表 OpenAI 官方产品或背书。

## 已实现的改进

- 语义段配音、按标点控制插入停顿、段间音量调整与边缘平滑，减少过碎分段造成的断裂。
- 章节动作相位延续、减少循环重复端点、完整主音轨与统一 25 fps 合成，改善章节衔接。
- 中文词组、数字单位与英文术语保护，改善字幕分行。
- 单 GPU 队列、独立重试目录、后台单实例锁、上传限制、超时清理、错误反馈与成片原子替换。
- 通用品牌界面、可配置路径、素材与运行数据隔离、源码导出检查。

这些是相对于本工作台早期流水线的改进，不是上游模型基准排名。实现与历史单样例数据见仓库中的 `docs/PRODUCT.md`。

## 验证与限制

18 项回归、前端 lint、类型检查与构建通过。此前完成过真实 GPU 短口播验证；详细范围见 `docs/AUDIT-2026-09-06.md`。

当前仍是实验版：模型环境需单独安装，主要验证平台为 Ubuntu / WSL2 + NVIDIA。字幕尚非逐字强制对齐，没有情绪控制或运行中取消；不能保证消除所有抖动、循环动作或听感问题。仅适合本机单用户，不要暴露到公网。

源码与附件均不包含私人形象、声音、文案、成片、数据库、日志或模型权重。GitHub 自动生成的源码下载与附带 SHA-256 清单的手工源码包内容组织略有不同，均为源码发布，不是安装程序。
